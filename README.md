## What is and why I made LarpOS
LarpOS is a custom OS built for the hack club YSWS challenge, Stardance. I built it because I was really interested in the Operating System tutorial as one of my friends made their own OS and my name in slack is @NotALarp, leading me to make it about Larping (LarpOS). ## Features

- Custom desktop with a "Larp Larp Larp Sahur" themed background
- Four functional windows: Terminal, Welcome, Settings and About Me
- Working terminal app with commands: `help`, `clear`, `about`, `date`, `larp `, `theme`
- Welcome window with a link to a how to larp like a pro guide
- About Me window linking to my GitHub profile
- Bar at the bottom with a live clock
- Functional app buttons which sit in the home screen
- A feature where you can resize windows by grabbing the bottom-right of the window and dragging your mouse
- A new style which is based on MacOS which has traffic lights and makes the OS much easier to navigate
- A light and dark theme
- More, check it out using the link above!
