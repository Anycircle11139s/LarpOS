# LarpOS™

LarpOS is a custom web Operating System based on Larping and Larp Larp Larp Sahur.

## Status and features
Currently, LarpOS is the bare bones of a functional web OS. I followed the guide and completed the tutorial enough so it qualifies for the first webOS mission. Once it gets approved, I'll work on it more so I can polish it and actually make it a good OS. It contains a "Larp Larp Larp Sahur" image as the background and 3 different windows. There is a terminal window which lets you type in some commands like help, clear, about and date. There is a welcome window which says welcome to LarpOS and a button which leads to a guide on how to larp. There is also a window which has an about me and a link to my github profile. In my top bar, I have the current time and buttons to open and close the windows.

## What is and why I made LarpOS
LarpOS is a custom OS built for the hack club YSWS challenge, Stardance. I built it because I was really interested in the Operating System tutorial as one of my friends made their own OS and my name in slack is @NotALarp, leading me to make it about Larping (LarpOS).

**[Try LarpOS live](https://anycircle11139s.github.io/LarpOS/)**

## Features

- Custom desktop with a "Larp Larp Larp Sahur" themed background
- Three functional windows: Terminal, Welcome, and About Me
- Working terminal app with commands: `help`, `clear`, `about`, `date`
- Welcome window with a link to a how to larp like a pro guide
- About Me window linking to my GitHub profile
- Top bar with a live clock and window open/close controls
