# LarpOS™

LarpOS is a custom web Operating System based on Larping and Larp Larp Larp Sahur.


**[Try LarpOS live](https://anycircle11139s.github.io/LarpOS/)**

## Quick Start

Just open the link above

## Features

- Custom desktop with a "Larp Larp Larp Sahur" themed background
- Three functional windows: Terminal, Welcome, and About Me
- Working terminal app with commands: `help`, `clear`, `about`, `date`
- Welcome window with a link to a "how to larp" guide
- About Me window linking to my GitHub profile
- Top bar with a live clock and window open/close controls

## Built With

- HTML
- CSS
- JavaScript
